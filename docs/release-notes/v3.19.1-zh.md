# CC Switch Remote v3.19.1

本版以 CC Switch 上游 v3.19.1 正式版为基线，完整合入 v3.19.0 与 v3.19.1 的功能、安全修复和性能优化，并完成 CC Switch Remote 的远程目标适配。重点包括：Codex 原生 Responses 供应商扩展、工具结果媒体转换、models.dev 定价同步、Grok Build 路由与用量能力、安全加固，以及远程 Helper 对这些流程的闭环支持。

---

## 主要更新

### Codex 原生 Responses 供应商

- DeepSeek 与火山方舟 Coding Plan 改为原生 Responses 直连，不再要求本地路由做 Chat 协议转换。
- 新增腾讯混元 TokenHub Codex 预设，包含 Responses 端点、模型目录和备用地址。
- DeepSeek 官方端点可使用厂商模型目录镜像，保留 freeform `apply_patch`、搜索和推理能力声明。
- 切回 OpenAI Official 时会清理仅包含旧第三方 API Key 的 `auth.json`，避免 Codex 卡在 401 且无法重新登录；OAuth、个人访问令牌等真实官方凭据不会被删除。

### Grok Build 完整性

- 修复 Grok Build 在图形界面中执行原生升级时找不到 Node/npm 的问题。
- 补齐 Grok Build 的代理路由、故障转移、环境变量冲突检测和稳定会话标识。
- 支持读取 Grok 官方订阅额度，并从官方会话日志导入用量。
- 远程目标补齐 Grok Build 的供应商、官方 seed 恢复、路由预检、首页与设置状态、daemon 清理及用量查询链路。

### 工具结果媒体转换

- 代理转换会从工具结果中识别图片、文件和音频，不再把大段 base64 当普通文本发送给上游。
- Codex、Claude、Gemini、Grok Build 等转换桥按目标协议重新构造媒体块，显著减少截图类会话的上下文膨胀。
- 不支持图片的供应商仍可使用既有回退机制，普通纯文本工具结果保持原有行为。

### 用量与定价

- 修复 Claude Desktop 代理记录与 Claude 会话日志重复计费的问题。
- 新增 models.dev 自动定价同步，并保留内置定价作为离线回退。
- 远程设置使用目标感知的 models.dev 状态、同步命令和查询缓存；同步动作由远程 Helper 执行，不会读写本地目标的数据。
- 补齐多项 GPT、Gemini、Kimi、GLM、Qwen 与 Claude 模型定价，并对已有种子价格与厂商价格做校正。
- Grok Build 成本回填使用与实时记录一致的缓存 token 口径。

### 安全与导入

- Skill 仓库下载增加路径穿越防护、归档大小和条目数量限制，并校验仓库坐标及安装目录。
- 数据库 SQL 导入拒绝 `ATTACH`、`DETACH`、危险虚表和越界文件操作。
- 深链导入确认页完整显示 MCP 命令、参数、URL、环境变量和用量脚本；风险值会提示，敏感值会脱敏。
- URL-safe Base64 深链载荷现在与后端使用同一解码规则，避免确认页内容与实际导入内容不一致。
- 深链携带的用量脚本默认禁用，用户审阅后才可启用。
- 修复通用配置对象遍历中的原型污染风险、终端工作目录命令转义问题，以及多个畸形配置/响应导致的崩溃路径。

### 性能与界面

- Codex fork 会话导入会缓存父时间线，减少重复解析。
- 工具栏应用切换器统一为图标模式，应用名称通过提示与无障碍标签保留。
- 修复繁体中文工具管理文案与多处缺失翻译。
- 清理无调用代码和不再使用的前端依赖，减少构建与维护负担。

## 远程管理适配

本版没有把“页面出现”当作远程功能完成。相关流程按远程目标重新核对了状态源、命令执行、持久化、刷新和失败处理：

- models.dev 定价同步经 `remoteApi` 和 Helper capability 执行，缓存键包含目标，远程页面不会读取本地同步状态。
- Grok Build 的供应商切换、官方 seed 恢复、路由开关、预检、daemon 状态和用量会话均使用远程服务器自己的数据库与配置文件。
- Helper 的工具安装/升级命令继承远程设置中的全局出站代理环境，Node/npm 锚定路径与本地共享同一套 Rust 生命周期逻辑。
- 本次新增的 models.dev 与 Grok Build 远程写入路径在失败时保留原有远程状态；命令级错误不会因为并非传输故障而销毁长连接 Helper 会话。
- Helper capability 已同步到本版新增命令；models.dev 等依赖新 capability 的入口会在旧 Helper 上隐藏或禁用。

## 可靠性修复

- 修复关闭路由后仍残留 Live 接管状态时，供应商切换同步等待代理任务而发生死锁的问题。
- 修复供应商切换数据库提交失败后，本地当前供应商标记没有回滚的问题；Live 配置、数据库和当前供应商设置现在会保持在失败前状态。
- 修复 Grok Build 官方供应商在远程目标不能按固定 seed 恢复的问题。
- 修复远程工具安装和升级未继承全局出站代理的问题。

## 升级说明

- 本版应用数据库 schema 仍为 v16，没有新增数据库迁移。
- 桌面应用可通过“设置 → 关于 → 检查更新”升级；应用内更新元数据与签名来自本项目 Release。
- Remote Helper 由远程服务器管理页安装或更新，资产发布在 `remote-helper-latest`。
- 旧版本创建的供应商会保留已保存的地址和模型设置；需要采用新版预设值时，请编辑现有供应商或从新版预设重新创建。
- macOS 构建会在发布环境具备完整 Apple 凭据时执行签名、公证和验证；若凭据不可用，Release 工作流会明确标记为未签名构建。
