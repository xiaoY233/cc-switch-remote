# CC Switch Remote v3.18.0

This release merges upstream CC Switch v3.18.0 and adapts the new functionality to the remote-management fork.

## Highlights

- Merged upstream v3.18.0 features: Grok Build support, xAI OAuth, xAI/Grok presets, Codex Responses compatibility fixes, Codex tool-call streaming fixes, Codex usage rebuild, persistent redacted diagnostics, and preset/pricing updates.
- Adapted Grok Build for remote management: provider forms, route visibility, proxy routing, MCP/Skills/session support, tool lifecycle checks, and helper CLI paths now include Grok Build where applicable.
- Adapted xAI OAuth for local and remote targets: Auth Center, Claude Code, Claude Desktop, Codex provider forms, model fetching, and remote helper commands use the selected management target instead of falling back to local state.
- Preserved fork identity and update flow: product name, bundle identifier, updater endpoint, helper installer repository, and release asset names remain under `xiaoY233/cc-switch-remote`.
- Included the upstream Codex tool-call fix relevant to `Invalid tool parameters` / empty `call_id` style failures, with regression coverage for streamed tool-call identity and ordering.

## Verification

- TypeScript check: `./node_modules/.bin/tsc --noEmit`
- Frontend targeted tests: 11 files / 85 tests
- Rust formatting: `cargo fmt --check --manifest-path src-tauri/Cargo.toml`
- Remote helper compile: `cargo check --manifest-path src-tauri/Cargo.toml --bin cc-switch-remote-helper --no-default-features --features proxy-runtime`
- Codex streaming regression tests: 20 tests
- Remote helper / CLI regression tests: 29 tests
- Dev startup smoke test: Tauri dev shell launched against the isolated development database at `~/.cc-switch-remote-dev/cc-switch.db`

`pnpm run dev` may be blocked on machines using pnpm 11 build-script approval until the local pnpm trust configuration is approved. The app itself was smoke-tested by launching Vite and Tauri directly without changing repository configuration.
