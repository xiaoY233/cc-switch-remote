# CC Switch Remote v3.19.2

本版以 CC Switch 上游 `v3.19.2` 正式标签为稳定基线，同步其管理列表、运行时模型、用量、备份、安全限制和界面性能优化，并完成 CC Switch Remote 的本地/远程目标适配与发布边界审计。

## 主要更新

- MCP、Prompts 与 Skills 管理页支持搜索、批量启停和顺序执行的失败反馈；远程目标使用独立查询键、Helper 命令和刷新链路。
- OpenCode/OMO 可从目标主机运行时获取模型；模型输出、行长和进程输出均有边界限制。
- Auth Center 展示 Codex、xAI 与 Copilot 账户额度；额度缓存、最近成功值和 OAuth 轮询按完整远程连接身份隔离。
- Codex 会话用量导入支持交错会话增量、持久游标和幂等同步；备份、Skill 更新与代理转换采用上游 v3.19.2 的共享性能优化。
- 路由状态在窗口失活时暂停动画，应用切换器、供应商预设、多语言推广文案和 Qwen3.8 Max 内置定价同步到稳定基线。

## 远程管理与隔离修复

- 长寿命 Remote Helper session 会比较主机、端口、用户、Helper 路径、认证方式、密钥路径和密码指纹；连接变化会关闭旧 session，并以 generation/CAS 防止迟到结果覆盖新主机。
- 远程 provider、用量、会话、路由、Settings、Tools、Import/Export、OpenClaw、Hermes 和 Managed Auth 状态统一按连接代际失效；目标切换后不会展示或操作上一主机的数据。
- Settings 与环境备份只写入 CC Switch Remote 的独立目录，拒绝 `~/.cc-switch` 及其符号链接别名；不会覆盖上游 CC Switch 数据。
- 桌面与 Helper 共用 Settings 事务：原子替换文件、保留 WebDAV/S3 凭据及同步元数据、保留后端迁移标记，并在 Codex 历史迁移延后时返回结构化 warning 和持久重试意图。
- Helper 接受无 `data` 的 unit 成功响应；业务错误不会销毁长连接 session。新版桌面同时兼容旧 Helper 的布尔保存回执。
- Skill 下载 URL、归档路径和大小/条目限制进一步收紧；Helper 测试工作流强制使用系统临时隔离目录并拒绝用户数据目录与符号链接逃逸。

## 升级说明

- 应用版本、Cargo 版本与 Tauri 版本统一为 `3.19.2`；数据库 schema 仍为 v16。
- 正常启动时可通过“设置 → 关于 → 检查更新”升级；数据库恢复界面的更新命令不依赖已初始化的 `AppState`。
- Remote Helper 由远程服务器管理页安装或更新，最新资产发布到 `remote-helper-latest`。
- 更新器元数据、下载地址和签名公钥均指向 `xiaoY233/cc-switch-remote`；`latest.json` 会在全部平台资产上传后生成并校验签名 key id。
- 本次发布不会合入上游 `v3.19.2` 标签之后的提交。
