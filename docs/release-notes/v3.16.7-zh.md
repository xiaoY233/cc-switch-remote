# CC Switch Remote v3.16.7

> **上游基线**：CC Switch `v3.16.3`
>
> **远程版构建**：`cc-switch-remote v3.16.7`
>
> 本版本用于发布当前远程管理分支的完整应用与 Helper 构建。`v3.16.6` 已经存在，因此本轮推进到 `v3.16.7`，保证 Tauri updater 可以从旧版本正常升级。

---

## 概览

本版重点是发布准备和远程管理文档补齐，同时保留 `cc-switch-remote` 的主线方向：本地和远程是独立目标，远程主机通过纯 CLI Helper 执行真实管理动作，桌面端只保存远程连接配置、连接密钥和健康检查缓存。

## 远程 Helper

远程 Helper 与桌面应用分开发版。发布本版时需要同时更新 `remote-helper-latest`，确保远程主机安装到当前 commit 构建的纯 CLI Helper。

- Helper release tag: `remote-helper-latest`
- Asset 前缀：`cc-switch-remote-helper-*`
- 目标：Linux x86_64、Linux arm64、macOS universal

---

## 升级提醒

- 更新桌面应用后，建议进入“远程服务器”页面检查每台远程主机的 Helper 是否为最新构建。
- 如果使用远程路由、远程供应商、远程工具环境或远程设置，请升级后先执行一次健康检查。
- macOS 构建当前未进行 Apple Developer ID 签名和公证，首次打开可能需要在系统设置中手动允许。
