# CC Switch Remote v3.16.15

> **上游基线**：CC Switch `v3.16.5`
>
> **远程版构建**：`cc-switch-remote v3.16.15`
>
> 本版本收敛远程应用路由的 daemon 常驻、应用接管前置条件和首页/设置页开关状态一致性。

---

## 远程路由修复

### 复用已运行的远程路由 daemon

远程路由 daemon/systemd 已经在监听端口时，短生命周期 helper 不再尝试再次启动并绑定同一端口，避免启用应用路由时报：

```text
Address already in use (os error 98)
```

### 启用应用路由前增加 preflight

远程 helper 新增应用路由启用前检查，启用 Claude / Codex / Gemini 应用路由前会确认：

- 目标应用存在当前供应商。
- 目标应用的 Live 配置文件可读取。
- 当前 helper 构建支持远程路由 runtime。

如果条件不满足，helper 会在写入远程状态前返回明确原因，不会留下半更新状态。

### 首页和设置页禁用不可用开关

远程首页应用路由开关和设置页应用路由开关现在会读取同一套 preflight 结果。当前应用不可启用远程路由时，开关会禁用并在提示中显示原因，例如未选择当前供应商或 Gemini `.env` 不存在。
