# CC Switch Remote v3.17.1

本版在上游 v3.17.0 基础上，补齐远程管理侧的同步适配，重点收敛“页面看起来有入口，但实际仍读写本地状态”的漂移问题。

## 远程管理同步改造

- 远程 Project Profiles 接入 helper：支持列表、创建、更新、删除、应用、清除当前项目。
- 远程公共配置接入 helper：Claude / Codex / Gemini 的 common config 读取、保存、TOML 合并与提取走远程目标。
- OMO / OMO Slim 远程同步补齐：读取远程配置文件、读取当前 OMO provider、停用当前 OMO、模型来源读取 live provider ids。
- OpenCode / OMO 相关缓存刷新改为 target-aware，避免远程操作后读到本地或旧缓存。
- 远程添加 Codex Official 时不再触发本地官方供应商 seed 流程，避免污染本地数据库。
- helper capability 新增 `profiles`、`common-config`、`omo`。

## 验证范围

发布前已执行前端 target-routing 测试、类型检查、Rust helper/CLI 测试、helper 二进制编译检查、Rust 全量 check、格式检查与 diff 空白检查。

> 本版仍建议在升级 helper 后，对真实远程服务器执行一次 Project Profiles、common config 与 OMO/OMO Slim 的端到端操作验证。
