# CC Switch Remote v3.20.1

本版以 CC Switch 上游 `v3.20.0` 正式标签为稳定基线，发布 CC Switch Remote 的 Windows 构建修复。

## 修复

- 恢复 Windows 启动目录解析所需的 `windows_shell_compatible_path`。该函数将 `std::fs::canonicalize` 产生的 `\\?\\` 本地路径与 UNC 路径转换为 `cmd.exe` 可调用的形式，保证批处理启动路径可用。
- 版本元数据统一为 `3.20.1`：`package.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock` 与 `src-tauri/tauri.conf.json` 保持一致。

## 升级说明

- 正常启动时可通过“设置 → 关于 → 检查更新”升级；数据库恢复界面的更新命令不依赖已初始化的 `AppState`。
- 更新器元数据、下载地址和签名公钥均指向 `xiaoY233/cc-switch-remote`；`latest.json` 在全部平台资产上传后生成，并校验签名 key id。
- Remote Helper 由远程服务器管理页安装或更新，资产发布到 `remote-helper-latest`。

**上游基线**：[CC Switch v3.20.0](https://github.com/farion1231/cc-switch/releases/tag/v3.20.0)
