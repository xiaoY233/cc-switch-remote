# CC Switch Remote v3.16.14

> **上游基线**：CC Switch `v3.16.5`
>
> **远程版构建**：`cc-switch-remote v3.16.14`
>
> 本版本修复 fork 后应用内更新签名链不一致的问题，并为后续发布增加 updater 签名校验防线。

---

## 重要修复

### 修复应用内更新无法安装

之前的 release 产物可以从 GitHub 正常下载，但 Tauri updater 在下载完成后的签名校验阶段会失败，导致应用内更新回退到手动更新。

本版本重新生成并配置了本 fork 自己的 Tauri updater 签名密钥：

- App 内置 updater 公钥已更新为当前 fork 的公钥。
- GitHub Actions `TAURI_SIGNING_PRIVATE_KEY` 已切换为匹配的新私钥。
- Release workflow 会在上传 `latest.json` 前校验所有平台签名 key id 是否匹配内置公钥。
- Release maintenance workflow 同样会校验，避免手动刷新 `latest.json` 时绕过检查。

> 注意：已经安装旧版本的用户，由于旧版本内置的是旧公钥，可能仍需要手动安装本版本一次。安装 v3.16.14 后，后续应用内更新会使用新的签名链。

### 更新失败日志更明确

应用内更新下载阶段如果实际是签名校验失败，后端日志现在会明确记录下载或签名校验错误，后续排查不会再只停留在“开始下载应用更新”。
